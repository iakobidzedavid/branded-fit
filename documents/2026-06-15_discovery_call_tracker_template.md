# Discovery Call Tracker — Step 21 Assumption Validation (Step 23 Pilot Customers)
**Framework version:** 1.0  
**Date created:** 2026-06-15  
**Purpose:** Collect structured discovery call data from 5 Brand Drop Pilot customers (Vanta, Linear, Census, Hex, Mercury) to validate 6 critical business assumptions for annual contract viability.

---

## INSTRUCTIONS FOR CALL EXECUTOR

**Before each call:**
1. Confirm prospect has agreed to participate (calendar invitation sent + accepted)
2. Send prospect the 3-minute brief + storefront mockups 24 hours in advance
3. Set up Zoom recording (with consent) — you'll need the transcript for accuracy
4. Review their pilot history (see "Pilot Context" column below)
5. Have this tracker open during call with pen + paper for real-time notes

**During each call (45–60 minutes):**
1. Follow the agenda in Section 2 exactly — no deviations
2. Capture word-for-word quotes in "Verbatim quote" fields
3. Use 1–5 scales where indicated; don't approximate
4. For Van Westendorp, ask the exact questions in sequence
5. Log objections with specific language the prospect used

**After each call:**
1. Complete all fields within 2 hours (memory is fresh)
2. Timestamp the completed tracker
3. Flag any answers that seem inconsistent or need clarification
4. If prospect didn't answer a question, mark as "N/A — prospect deferred" (don't guess)
5. Upload recording + transcript to shared folder
