# Product Catalog Upload and Store Configuration Implementation

**Date:** 2026-06-03  
**Task:** Product catalog upload function and store configuration

## Overview

Implemented product upload functionality that accepts Printify pipeline output and creates Shopify products via the Admin API. Added store configuration for tax rates, shipping zones, and draft mode.

## Changes

### 1. Enhanced Shopify Client Library (`src/lib/shopify.ts`)

#### New Interfaces
- **ProductVariant**: Defines product variant structure (sku, price, options)
- **ProductInput**: Product data structure for creation (title, description, images, variants)
- **TaxRate**: Tax rate configuration (name, rate, country, province)
- **ShippingZone**: Shipping zone configuration (name, countries, rates)

#### New Methods in ShopifyClient Interface
```typescript
createProduct(accessToken, product): Promise<{ id, title }>
createTaxRate(accessToken, taxRate): Promise<boolean>
createShippingZone(accessToken, zone): Promise<boolean>
setDraftMode(accessToken): Promise<boolean>
```

#### Implementation Details

**createProduct()**
- Accepts ProductInput with product metadata and variants
- Maps variants to Shopify format with SKU, price, color, and size options
- Creates product images with proper alt text
- Returns Shopify product ID and title
- Handles errors and provides detailed error messages

**createTaxRate()**
- Creates tax rates on Shopify Admin API
- Supports optional country and province configuration
- Used for setting up tax compliance

**createShippingZone()**
- Creates shipping zones with weight-based rates
- Maps country codes to shipping zones
- Configures shipping rates per zone

**setDraftMode()**
- Sets store to draft mode (setup_required = true)
- Prevents accidental publishing before products are ready
- Called automatically during store provisioning

### 2. Product Upload API (`src/app/api/products/upload/route.ts`)

**Endpoint:** `POST /api/products/upload`

**Request Body:**
```json
{
  "domain": "example.com",
  "shopifyAccessToken": "shpat_...",
  "shopName": "example.myshopify.com",
  "taxRates": [
    {
      "name": "US Sales Tax",
      "rate": 0.08,
      "country": "US",
      "province": "CA"
    }
  ],
  "shippingZones": [
    {
      "name": "US Standard",
      "countries": ["US"],
      "rates": [
        {
          "name": "Standard Shipping",
          "price": 5.00
        }
      ]
    }
  ]
}
```

**Response:**
```json
{
  "success": true,
  "domain": "example.com",
  "productsCreated": 5,
  "products": [
    {
      "sku": "HWT-001",
      "title": "Heavyweight T-Shirt",
      "shopifyId": "gid://shopify/Product/123456"
    }
  ],
  "failedProducts": [],
  "taxRatesConfigured": 1,
  "taxRates": ["US Sales Tax"],
  "failedTaxRates": [],
  "shippingZonesConfigured": 1,
  "shippingZones": ["US Standard"],
  "failedShippingZones": []
}
```

**Flow:**
1. Retrieves products from Supabase (generated by Printify pipeline)
2. Maps each product to ProductInput format
3. Creates products on Shopify with variants, pricing, and images
4. Configures tax rates if provided
5. Configures shipping zones if provided
6. Returns summary of created products and failed operations

### 3. Store Configuration API (`src/app/api/store/configure/route.ts`)

**Endpoint:** `POST /api/store/configure`

**Request Body:**
```json
{
  "shopifyAccessToken": "shpat_...",
  "shopName": "example.myshopify.com",
  "taxRates": [...],
  "shippingZones": [...]
}
```

**Response:**
```json
{
  "success": true,
  "draftMode": true,
  "taxRatesConfigured": 1,
  "taxRates": ["US Sales Tax"],
  "failedTaxRates": [],
  "shippingZonesConfigured": 1,
  "shippingZones": ["US Standard"],
  "failedShippingZones": []
}
```

**Features:**
- Standalone endpoint for configuring existing stores
- Sets draft mode by default
- Handles partial failures gracefully
- Returns detailed configuration status

## Database Integration

Uses existing Supabase schema:
- **products** table: Stores product data from Printify pipeline
  - domain, sku, product_name, mockup_image_url
  - variants (JSONB with color/size combinations)
  - pricing (JSONB with basePrice, markup, finalPrice)

- **stores** table: Stores store metadata
  - domain, shopify_store_id, shopify_store_url
  - status (draft/active/published)

## Workflow

### Complete Workflow with Products

1. **Extract Brand Assets**
   - Call `/api/brandfetch` → Extracts colors, logos, typography
   - Stores in `brand_extracts` table

2. **Generate Mockup Products**
   - Call `/api/printify` → Creates product variants with pricing
   - Stores in `products` table with mockup images

3. **Provision Store**
   - Call `/api/shopify` → Creates Shopify store
   - Sets draft mode automatically
   - Stores in `stores` table

4. **Upload Products & Configure Store**
   - Call `/api/products/upload` → Creates Shopify products with variants
   - Configures tax rates and shipping zones
   - Returns product creation status

### Alternative: Configure Existing Store

- Call `/api/store/configure` → Adds/updates tax rates and shipping zones to existing store
- Useful for updating store configuration independently

## Error Handling

- Missing required fields return 400 errors with clear messages
- Partial failures are tracked (failedProducts, failedTaxRates, failedShippingZones)
- Individual product creation failures don't block other products
- Network/API errors are logged and reported
- Draft mode failures are non-blocking (only warn, don't fail)

## Security Considerations

- Access tokens are passed per-request (not stored)
- Proper error handling without exposing sensitive details
- Shopify API token validation through actual API calls
- No hardcoded credentials in code
